# Product Overview

SophisticatedMASは、Minecraft 1.20.1向けのアドオンMODで、**Mine and Slash (MAS)** と **Sophisticated Backpacks** の統合を実現します。プレイヤーのインベントリ管理とアイテム処理を劇的に効率化することを目的としています。

## Core Capabilities

1. **自動サルベージ統合** - バックパック内のMASギアを自動分解し、素材を回収
2. **作業台アクセス拡張** - バックパックUIから直接MAS職業作業台（Salvaging/Crafting/Cooking Station）にアクセス
3. **設定連携** - プレイヤーのMAS自動サルベージ設定（レア度/タイプフィルター）を尊重

## Target Use Cases

### 主要シナリオ
- **ダンジョン探索効率化**: バックパックが自動的に不要なギアを分解し、インベントリ圧迫を防ぐ
- **モバイル作業環境**: ポータブルバックパックから作業台機能にアクセスし、拠点への往復を削減
- **リソース管理最適化**: サルベージ設定（レア度別）に基づいて、価値の低いアイテムのみを自動処理

### ユーザー体験
既存のMAS/Sophisticated Backpacks体験を統合・拡張するものであり、新しい学習コストを最小限に抑える設計。プレイヤーは既存の設定やワークフローをそのまま活用できる。

## Value Proposition

### 独自性
- **既存MODのシナジー**: 2つの人気MODの機能を自然に連携
- **ノンブロッキング設計**: プレイヤーの既存設定や動作を上書きせず、拡張のみを提供
- **API駆動**: MASとSophisticated Backpacks両方の公開APIを活用し、互換性を維持

### プレイヤーへの価値
時間効率（往復削減）、インベントリ管理の自動化、カスタマイズ可能な自動処理により、エンドゲームコンテンツへの集中を支援。
